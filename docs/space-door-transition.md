# Space door navigation

A persistent overlay slides two steel panels inward, commits navigation while fully closed, then slides them outward from the center. Normal timing is 280ms closing + a minimum 70ms hold + 320ms opening. Async Air Raid setup can extend the closed hold. Reduced-motion timing is 50/30/70ms. Main App screens, Air Raid briefing pages, launch/restart, pause/resume, settings, difficulty and stage-picker menus use the shared sequence. Defense settings uses it too.

Gameplay events such as damage, boss phase changes, deaths and stage announcements keep their existing presentation. Network synchronization continues during cosmetic transitions. Local Air Raid simulation holds while the overlay blocks input; its rAF clock still advances, preventing catch-up after reveal. A portal makes the same overlay span the title, menus and both games, including document fullscreen. Idle overlay is display:none. Only two image-backed CSS transforms animate; no Canvas redraw, animated blur, new particle system or per-frame React updates are added.

Related actions during closure are batched, so closing a stage picker and launching its stage are not separated. Keyboard/pointer/touch input is blocked during transitions and content is inert. Focus is restored after reveal. Unmount cancels outstanding navigation timers.

Artwork: built-in ImageGen, normalized to a 159126-byte WebP used once by both leaves via background positioning. Original generation prompt:

Create a production game UI background texture: an industrial spaceship bulkhead door, fully CLOSED, two equal solid steel door leaves meeting at an absolutely straight vertical seam at EXACT image horizontal center. New original design inspired by functional sci-fi airlock doors. Landscape image, wide 16:9 composition, front-on orthographic view, no perspective. Dark gunmetal and titanium panels with detailed recessed bevels, precision machined seams, occasional small bolts, black-and-amber diagonal hazard strips along top and bottom, slim restrained cyan status lights, tasteful weathering. Both leaves extend all the way to the top bottom and outer sides of canvas, no surrounding doorway frame, no visible room, no gap at center, no windows, no handles crossing seam, no objects crossing center seam, no text or lettering. Overall dark enough to feel like a space warship, crisp premium realistic painted-metal game asset. It will be split at center and its two halves will slide horizontally apart to reveal a menu behind it. Symmetrical structural language with subtle asymmetric panel details. Completely opaque background.

Validation: production build, asset packaging check, and `node scripts/test-space-door.mjs` cover navigation timing, action batching, async preparation, reduced motion, input lock and cancellation. Browser screenshots and device performance remain unverified because Chromium cannot launch in this environment.
