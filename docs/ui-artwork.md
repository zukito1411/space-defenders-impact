All artwork fills the canvas. No text, no letters, no numbers, no logos, no badges, no interface, no icons, no circles/reticles/graphic shapes, no card layouts, no mockup. Not vector art, not a flat gradient. Broad atmospheric lighting, fine authored surface detail, game art rather than stock website imagery.
