# Boss projectile artwork

The shared boss atlas provides dedicated textures for the existing squid bubble, ink and spine attacks, and the snake's fang, venom spit and lingering poison cloud. The GPU foreground uses those tiles with existing sprite pools and attack lifetimes. If the atlas fails to load, the existing procedural textures remain the fallback. The Canvas foreground keeps its existing special-attack art. Beams and other boss attacks keep their established rendering.

Player pulse, laser, spread, scatter and needle visuals are wider for readability; collision sizes and damage are unchanged.

The atlas was generated with the built-in image tool from these instructions: "Production 2D game VFX sprite atlas for a detailed sci-fi space shooter. Transparent RGBA square sheet, precisely 4 columns by 4 rows equal cells, single isolated centered effect per cell, generous transparent gutters, no grid, no text. All pointed projectiles face RIGHT. Row 1: translucent spherical pink-violet squid energy bubble with pearlescent rim; organic magenta squid ink bolt with a fluid tail left; sharp pink organic squid spine pointing right; ivory snake fang with luminous lime venom pointing right. Row 2: bright acid-green venom spit globule with short tail pointing right; diffuse translucent green toxic gas cloud with wisps, no hard outline; violet void orb with dark center and magenta corona; gold-red mechanical boss energy bolt pointing right. Row 3: red hot enemy plasma orb; orange fire impact; blue electric hit; amber muzzle flash. Row 4: green venom splash; pink bubble burst; blue ship engine plume; tiny molten fragment. Crisp readable shapes at small game size, restrained glow, high-quality detailed game VFX, no opaque background, no checkerboard, no labels, no subjects spilling into adjacent cells."

A second image-generation pass removed the background and the squid inside the bubble. The sheet was normalized to 1024px, with 32px gutters on every 256px cell. Three shared atlases now load instead of two, adding texture memory. Device FPS and visual quality in a running game remain unmeasured.
